The Google sign-in and "Forgot password?" buttons were not clicked, because both would hit their auth backend.

- 2026-10-23 · Phase R · The human approved #76–82. Applied #76 to §4.3 (`university_domains.campus_id/mail_host/returning_only` + `auth_providers`) and promoted #35 Q&A to P0.
- 2026-10-23 · Design · Brand set to cobalt `#0034D3` on cream `#F2ECE1`, with navy `#0B0838` + sky `#99CCFF` in dark mode (Cosmos refs C/D chosen by the human). This replaces the placeholder campus green. Four lane colours (violet/mint/cyan/cobalt) carry feature identity instead of a single accent. Violet tiles use white text, because navy on violet is only 3.7:1.
- 2026-10-23 · Repo · Kept `UOSBuddy_BUILD_PLAN.md` at the root for now, although §4.1 says `docs/BUILD_PLAN.md`. The human has it open; it moves in Phase 0's scaffold commit.
- 2026-10-23 · Phase 0 · Development runs on a hosted Supabase project (`pjddiybbcpiywusglysc`, ap-south-1 Mumbai, Free plan) instead of `supabase start`. This PC has 7.8 GB RAM and a nearly full C: drive, which cannot fit the Docker stack. `db:push` and `db:types` now target the linked project; `db:types:local` remains for CI.
- 2026-10-23 · Phase 1 · Kept university-email sign-in as planned (Google OAuth restricted to `uos.edu.pk` + email OTP fallback + freshman document path). Considered making uni email an optional verification only, because many students rarely use it; the human preferred the official-email login for its professional feel. Expect a large share of sign-ups to go through admin document review.
- 2026-10-23 · Phase 1 · Catalogue uses the uos.edu.pk faculty → department → program list (48 departments) rather than the 30 campus-banner names, because programs hang off the finer departments and batchmates are matched by program. Banner names are kept as `aliases` for search (e.g. "Computer Science & IT" → CS, IT, SE). "5th Semester Intake" programs stay separate (`bs_5th_semester`), since they form their own cohorts. Two-year MA/MSc and diplomas map to `other`, because the enum has no master's level.
- 2026-10-23 · Phase 1 · Roll-number letter R/S is the admission category (regular / self-support), stored as data and not mapped to `shift`, because self-support classes are not guaranteed to be evening. Launch is limited to the main Sargodha campus; sub-campuses come later through the existing `campuses` table. The verification review SLA is 12 hours. The catalogue is regenerated from `supabase/seed/uos-programs.txt` by `supabase/seed/build_catalogue.py`.
- 2026-10-23 · Phase 0 · Moved the build plan to `docs/BUILD_PLAN.md` (§4.1). Lighthouse 12 removed its PWA audit, so installability is checked in Playwright through Chrome's `Page.getInstallabilityErrors`, ignoring the `in-incognito` error that every Playwright context raises. AI service requests from Next.js are signed with HMAC-SHA256 over `timestamp.body` (`X-UOSB-Timestamp`/`X-UOSB-Signature`, 5-minute window); internal routes fail closed when the secret is unset.
- 2026-10-25 · Phase 1 · Supabase auth email goes through Gmail SMTP (app password) for development, because Supabase only allows editing templates with custom SMTP and there is no domain yet. Gmail caps at about 500 emails/day and may land in spam. Switch to Resend with a verified domain before launch.
- 2026-10-26 · Phase 1 · Status emails (submitted / approved / needs info / rejected) are sent over SMTP with nodemailer instead of the Resend SDK. Gmail works now, and Resend at launch is only an env change (smtp.resend.com), so `RESEND_API_KEY` became `SMTP_*` + `EMAIL_FROM`. Sending runs in `after()` and never throws, so a mail failure cannot undo a submission or a review decision.
- 2026-10-26 · Phase 1 · Document retention: `expired_verification_documents()` (SQL, pgTAP-tested) decides what is due, and `/api/cron/purge-documents` deletes it through the Storage API daily via Vercel Cron, guarded by `CRON_SECRET`. This replaces a pure pg_cron job because Supabase blocks direct deletes from storage tables. The rule also removes files orphaned by resubmissions and uploads never submitted.
